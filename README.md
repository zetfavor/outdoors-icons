# Outdoors · Product Iconography

A curated, extensible collection of product-specific vector icons for **My Outdoor Must-Haves**.

- Format: **SVG**; transparent background, 24 × 24 viewBox.
- Shared visual color: graphite **#5B5A56**.
- Stable paths: `icons/<key>.svg` (avoid renaming published icon keys).
- Intended use: Notion database page icons rendered by **outdoors.super.site**.
- Private product information, wishlists, Notion record identifiers and inventories are **not** stored in this public repository.

The four original hero design silhouettes (`tent`, `pillow`, `camera`, `cutlery`) preserve the **Tabler Icons** artwork (MIT license, https://github.com/tabler/tabler-icons), with graphite color substituted for currentColor. Other SVGs are original Outdoors line drawings preserved in the private Notion icon archive. See `manifest.json` for the mapping. This is an image-asset repository, not a copy of the private Notion product catalog.
